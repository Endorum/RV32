# RV32I quick reference

| Group                  | Instruction / assembly           | Exact encoding, inst[31] -> inst[0]                                           | What it does                                                                                                     |
| ---------------------- | -------------------------------- | ------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Upper / PC             | LUI lui rd, imm20          | imm[31:12] rd 0110111 (0x37)                                                | x[rd] = U                                                                                                      |
| Upper / PC             | AUIPC auipc rd, imm20      | imm[31:12] rd 0010111 (0x17)                                                | x[rd] = pc + U                                                                                                 |
| ALU immediate          | ADDI addi rd, rs1, imm12   | imm[11:0] rs1 000 rd 0010011 (0x13)                                         | x[rd] = x[rs1] + I                                                                                             |
| ALU immediate          | SLTI slti rd, rs1, imm12   | imm[11:0] rs1 010 rd 0010011 (0x13)                                         | x[rd] = (s32(x[rs1]) < s32(I)) ? 1 : 0                                                                         |
| ALU immediate          | SLTIU sltiu rd, rs1, imm12 | imm[11:0] rs1 011 rd 0010011 (0x13)                                         | x[rd] = (u32(x[rs1]) < u32(I)) ? 1 : 0; I is sign-extended first                                             |
| ALU immediate          | XORI xori rd, rs1, imm12   | imm[11:0] rs1 100 rd 0010011 (0x13)                                         | x[rd] = x[rs1] XOR I                                                                                           |
| ALU immediate          | ORI ori rd, rs1, imm12     | imm[11:0] rs1 110 rd 0010011 (0x13)                                         | x[rd] = x[rs1] OR I                                                                                            |
| ALU immediate          | ANDI andi rd, rs1, imm12   | imm[11:0] rs1 111 rd 0010011 (0x13)                                         | x[rd] = x[rs1] AND I                                                                                           |
| ALU immediate          | SLLI slli rd, rs1, shamt   | 0000000 shamt rs1 001 rd 0010011 (0x13)                                     | x[rd] = x[rs1] << shamt                                                                                        |
| ALU immediate          | SRLI srli rd, rs1, shamt   | 0000000 shamt rs1 101 rd 0010011 (0x13)                                     | x[rd] = u32(x[rs1]) >> shamt                                                                                   |
| ALU immediate          | SRAI srai rd, rs1, shamt   | 0100000 shamt rs1 101 rd 0010011 (0x13)                                     | x[rd] = s32(x[rs1]) >> shamt                                                                                   |
| ALU register           | ADD add rd, rs1, rs2       | 0000000 rs2 rs1 000 rd 0110011 (0x33)                                       | x[rd] = x[rs1] + x[rs2]                                                                                        |
| ALU register           | SUB sub rd, rs1, rs2       | 0100000 rs2 rs1 000 rd 0110011 (0x33)                                       | x[rd] = x[rs1] - x[rs2]                                                                                        |
| ALU register           | SLL sll rd, rs1, rs2       | 0000000 rs2 rs1 001 rd 0110011 (0x33)                                       | x[rd] = x[rs1] << x[rs2][4:0]                                                                                  |
| ALU register           | SLT slt rd, rs1, rs2       | 0000000 rs2 rs1 010 rd 0110011 (0x33)                                       | x[rd] = (s32(x[rs1]) < s32(x[rs2])) ? 1 : 0                                                                    |
| ALU register           | SLTU sltu rd, rs1, rs2     | 0000000 rs2 rs1 011 rd 0110011 (0x33)                                       | x[rd] = (u32(x[rs1]) < u32(x[rs2])) ? 1 : 0                                                                    |
| ALU register           | XOR xor rd, rs1, rs2       | 0000000 rs2 rs1 100 rd 0110011 (0x33)                                       | x[rd] = x[rs1] XOR x[rs2]                                                                                      |
| ALU register           | SRL srl rd, rs1, rs2       | 0000000 rs2 rs1 101 rd 0110011 (0x33)                                       | x[rd] = u32(x[rs1]) >> x[rs2][4:0]                                                                             |
| ALU register           | SRA sra rd, rs1, rs2       | 0100000 rs2 rs1 101 rd 0110011 (0x33)                                       | x[rd] = s32(x[rs1]) >> x[rs2][4:0]                                                                             |
| ALU register           | OR or rd, rs1, rs2         | 0000000 rs2 rs1 110 rd 0110011 (0x33)                                       | x[rd] = x[rs1] OR x[rs2]                                                                                       |
| ALU register           | AND and rd, rs1, rs2       | 0000000 rs2 rs1 111 rd 0110011 (0x33)                                       | x[rd] = x[rs1] AND x[rs2]                                                                                      |
| Load                   | LB lb rd, imm12(rs1)       | imm[11:0] rs1 000 rd 0000011 (0x03)                                         | x[rd] = sext32(M8[x[rs1] + I])                                                                                 |
| Load                   | LH lh rd, imm12(rs1)       | imm[11:0] rs1 001 rd 0000011 (0x03)                                         | x[rd] = sext32(M16[x[rs1] + I])                                                                                |
| Load                   | LW lw rd, imm12(rs1)       | imm[11:0] rs1 010 rd 0000011 (0x03)                                         | x[rd] = M32[x[rs1] + I]                                                                                        |
| Load                   | LBU lbu rd, imm12(rs1)     | imm[11:0] rs1 100 rd 0000011 (0x03)                                         | x[rd] = zext32(M8[x[rs1] + I])                                                                                 |
| Load                   | LHU lhu rd, imm12(rs1)     | imm[11:0] rs1 101 rd 0000011 (0x03)                                         | x[rd] = zext32(M16[x[rs1] + I])                                                                                |
| Store                  | SB sb rs2, imm12(rs1)      | imm[11:5] rs2 rs1 000 imm[4:0] 0100011 (0x23)                               | M8[x[rs1] + S] = x[rs2][7:0]                                                                                   |
| Store                  | SH sh rs2, imm12(rs1)      | imm[11:5] rs2 rs1 001 imm[4:0] 0100011 (0x23)                               | M16[x[rs1] + S] = x[rs2][15:0]                                                                                 |
| Store                  | SW sw rs2, imm12(rs1)      | imm[11:5] rs2 rs1 010 imm[4:0] 0100011 (0x23)                               | M32[x[rs1] + S] = x[rs2]                                                                                       |
| Branch                 | BEQ beq rs1, rs2, offset   | {imm[12],imm[10:5]} rs2 rs1 000 {imm[4:1],imm[11]} 1100011 (0x63)           | If x[rs1] == x[rs2], pc = pc + B; otherwise pc = pc + 4                                                    |
| Branch                 | BNE bne rs1, rs2, offset   | {imm[12],imm[10:5]} rs2 rs1 001 {imm[4:1],imm[11]} 1100011 (0x63)           | If x[rs1] != x[rs2], pc = pc + B; otherwise pc = pc + 4                                                    |
| Branch                 | BLT blt rs1, rs2, offset   | {imm[12],imm[10:5]} rs2 rs1 100 {imm[4:1],imm[11]} 1100011 (0x63)           | If s32(x[rs1]) < s32(x[rs2]), pc = pc + B; otherwise pc = pc + 4                                           |
| Branch                 | BGE bge rs1, rs2, offset   | {imm[12],imm[10:5]} rs2 rs1 101 {imm[4:1],imm[11]} 1100011 (0x63)           | If s32(x[rs1]) >= s32(x[rs2]), pc = pc + B; otherwise pc = pc + 4                                          |
| Branch                 | BLTU bltu rs1, rs2, offset | {imm[12],imm[10:5]} rs2 rs1 110 {imm[4:1],imm[11]} 1100011 (0x63)           | If u32(x[rs1]) < u32(x[rs2]), pc = pc + B; otherwise pc = pc + 4                                           |
| Branch                 | BGEU bgeu rs1, rs2, offset | {imm[12],imm[10:5]} rs2 rs1 111 {imm[4:1],imm[11]} 1100011 (0x63)           | If u32(x[rs1]) >= u32(x[rs2]), pc = pc + B; otherwise pc = pc + 4                                          |
| Jump                   | JAL jal rd, offset         | {imm[20],imm[10:1],imm[11],imm[19:12]} rd 1101111 (0x6F)                    | x[rd] = pc + 4; pc = pc + J                                                                                    |
| Jump                   | JALR jalr rd, imm12(rs1)   | imm[11:0] rs1 000 rd 1100111 (0x67)                                         | t = pc + 4; pc = (x[rs1] + I) AND 0xFFFFFFFE; x[rd] = t                                                        |
| Ordering               | FENCE fence pred, succ     | fm[3:0] pred[3:0] succ[3:0] rs1 000 rd 0001111 (0x0F)                       | Orders accesses in pred before accesses in succ; normal fm=0000; standard software uses rs1=rd=00000     |
| Environment            | ECALL ecall                | 000000000000 00000 000 00000 1110011 = 0x00000073; LE bytes 73 00 00 00   | Raises a precise environment-call trap                                                                           |
| Environment            | EBREAK ebreak              | 000000000001 00000 000 00000 1110011 = 0x00100073; LE bytes 73 00 10 00   | Raises a precise breakpoint trap                                                                                 |
| Named FENCE encoding   | FENCE.TSO fence.tso        | 1000 0011 0011 00000 000 00000 0001111 = 0x8330000F; LE bytes 0F 00 30 83 | Orders R->R/W and W->W, but not ordinary W->R; a specialized FENCE encoding, not an extra base instruction |
| Standard HINT encoding | PAUSE pause                | 0000 0001 0000 00000 000 00000 0001111 = 0x0100000F; LE bytes 0F 00 00 01 | No architectural state change; standardized by Zihintpause and may be ignored                                  |

| Item                  | Exact definition                                                                                                                                                                                                                                                                       |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| I immediate         | sext32(inst[31:20]); range -2048..2047                                                                                                                                                                                                                                             |
| S immediate         | sext32({inst[31:25],inst[11:7]}); range -2048..2047                                                                                                                                                                                                                                |
| B immediate         | sext32({inst[31],inst[7],inst[30:25],inst[11:8],1'b0}); range -4096..4094, always even                                                                                                                                                                                             |
| U immediate         | {inst[31:12],12'b0}; low 12 bits are zero                                                                                                                                                                                                                                            |
| J immediate         | sext32({inst[31],inst[19:12],inst[20],inst[30:21],1'b0}); range -1048576..1048574, always even                                                                                                                                                                                     |
| Shift amount          | shamt = inst[24:20]; range 0..31; register shifts use x[rs2][4:0]                                                                                                                                                                                                                |
| FENCE set bits        | In each 4-bit pred or succ field: I=1000, O=0100, R=0010, W=0001                                                                                                                                                                                                           |
| Arithmetic / notation | x[r] is register r; M8/M16/M32[a] is memory at address a; s32/u32 select signed/unsigned interpretation; integer results wrap modulo 2^32; x0 always reads as zero and discards writes                                                                                   |
| Word and byte order   | Encodings are 32-bit instruction words shown from bit 31 to bit 0. On a little-endian system, word 0xAABBCCDD is stored as bytes DD CC BB AA                                                                                                                                       |
| Scope                 | The 40 RV32I base instructions end at EBREAK. FENCE.TSO is a named FENCE encoding and PAUSE is a standardized HINT. FENCE.I is Zifencei; CSR instructions are Zicsr; multiply/divide, atomics, floating point, compressed, and privileged instructions are not RV32I |
